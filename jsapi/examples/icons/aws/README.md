# AWS Icons Catalog Example

This example generates a comprehensive visual catalog of all AWS4 icons available in the DrawIO JSAPI.

## What It Does

The script creates a tall diagram (8.5" wide, variable height) that displays all AWS service icons organized by category. Each icon is labeled with its service name, making it easy to browse available icons and their identifiers.

## Running the Example

```bash
npm install
npm start
```

The generated diagram will be saved to `output/aws-icons-catalog.drawio`.

## Output

The diagram includes:

- All AWS4 icon categories (Compute, Database, Storage, Networking, etc.)
- Icons arranged in a grid layout with labels
- Category headers separating each section
- Approximately 200+ AWS service icons

The diagram is designed to fit on 8.5" wide paper and extends vertically to accommodate all icons.

## Use Cases

This catalog is useful for:

- Discovering available AWS icons and their identifiers
- Reference when building AWS architecture diagrams
- Visual documentation of the icon library
- Selecting appropriate icons for your diagrams
