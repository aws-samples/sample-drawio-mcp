# Examples

Working examples demonstrating the drawio-jsapi SDK.

## Available Examples

| Example                       | Description                                 |
| ----------------------------- | ------------------------------------------- |
| [hello-drawio](hello-drawio/) | Basic flowchart with shapes and connections |
| [hello-aws4](hello-aws4/)     | AWS architecture diagram with service icons |

## Running Examples

Each example is a standalone Node.js project. To run an example:

```bash
cd <example-directory>
npm install
npm start
```

Generated diagrams are saved to the `output/` directory within each example.

## Opening Generated Diagrams

The `.drawio` files can be opened with:

- [diagrams.net](https://app.diagrams.net/) (web)
- [VS Code Draw.io Integration](https://marketplace.visualstudio.com/items?itemName=hediet.vscode-drawio) extension
- [draw.io Desktop](https://www.diagrams.net/) application
