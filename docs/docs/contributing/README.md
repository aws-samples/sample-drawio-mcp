# Contributing

This section provides information for developers who want to contribute to or extend the drawio-mcp project.

**Development** covers the repository structure, local setup, and testing procedures for both the JSAPI and MCP server components.

**CI/CD** explains the automated build and release pipeline, including how packages are published to GitLab Package Registry.

**NPM Package** documents the package publishing process, versioning strategy, and how to consume the published packages.
